APPROACH / 03
SMART AFFINITY-BASED ALLOCATION

A 5-phase pipeline that turns shipments
into fair, road-optimized SR routes.

From XLSX upload to LM allocation in under 2 minutes.

1
Data Ingestion & Cleanup

XLSX/CSV upload · auto column-detection (20+ aliases) · >50km filter · isolated-point outliers excluded · hub polygon from XB orchestration API.

2
Hub-Centric Angular Clustering

Sort by compass bearing from hub · split into equal pie-slice sectors — one per present SR · contiguous wedges, no route crossing.

3
Earnings-Based Fairness Rebalancing

Compute gross payout, fuel cost (₹2.5/km), net earnings per SR · iteratively swap boundary shipments · target ±₹50 spread across the team.

4
Route Optimization

Nearest-neighbor TSP from hub · Google Maps Directions API for real road routing · Leaflet + Google Maps toggle for visualization.

5
LM System Integration

Auto Keycloak (client_credentials) · bulk POST /expose/shipment/allocate · auto-confirm (OFD + trip) · one-click "Push All Routes".

APPENDIX — Q&A / A2
TOUGH QUESTIONS, READY ANSWERS

If they push, push back with data.

The six questions a CEO/COO will ask, and how you answer.

QHow is this different from existing allocation?

Existing is manual + pincode-based. v3 uses geo-coordinates, angular clustering, and earnings-based rebalancing — data-driven, not intuition-driven.

QWhat if SR count changes mid-day?

Re-run allocation with updated attendance — under 30 seconds. Engine is stateless on that axis.

QWill this work for other hubs?

Yes — change hub lat/lng in config and upload that hub's shipments. No code change required.

QWhat about reverse pickups (RVP)?

Forward-only today. RVP can be added as a separate allocation type using the same engine.

QGoogle Maps API cost at scale?

10k free calls/month. 10 SRs × 30 days = 300 calls/month — well inside free tier. 100 hubs = ~30k = ~$100/month.

QIs it production-ready?

Deployed on EC2 stage right now. Integrated with LM APIs. Needs pilot approval for one hub, then scale.

Keep these answers tight — confidence beats length
